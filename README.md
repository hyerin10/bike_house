## Env Scripts (Windows PowerShell)

- `.\run_dev.ps1` : 개발 환경으로 실행 (`.env.development`)
- `.\run_prod.ps1` : 운영 환경으로 실행 테스트 (`.env.production`)
- `.\build_prod.ps1` : 운영 환경으로 AAB 빌드
